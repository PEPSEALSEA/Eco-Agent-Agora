================================================================================
1. ภาพรวมโปรเจกต์
================================================================================

WongJraJa = เกมฝึกทักษะการเจรจา
ผู้เล่นคุยกับ AI ตัวละครหลายคน → ชนะ/แพ้ → ได้ feedback หลังจบ

Tech Stack:
- Frontend: Next.js 16 (static export) + React 19 + Tailwind + Framer Motion
- Backend: Cloudflare Worker → Google Sheets (ไม่ใช่ Supabase แม้มี schema)
- AI: Gemini 2.5 Flash (client-side + server evaluation)
- Voice: Gemini multimodal (Python Audio มีแต่ยังไม่เชื่อม)
- Deploy: Vercel + GitHub Actions (basePath: /Eco-Agent-Agora)

สถานะโดยรวม: โครงสร้างครบ ~70%
- UI และ user journey หลักทำได้แล้ว
- Logic หลังบ้านหลายส่วนยังไม่เชื่อมครบ

Core Loop ที่ต้องสมบูรณ์:
  เลือกด่าน → คุยเจรจา → ชนะ/แพ้ → Debrief → ปลดล็อกด่านถัดไป

Flow ที่เล่นจบได้ (ถ้า config backend ครบ):
  Landing → Login → เลือกด่าน → คุย AI → Win/Lose → Debrief (กด eval เอง)

สิ่งที่ UI มีแต่ logic ยังไม่ทำงาน:
  Trust/Anger · Dynamic Decisions · Reigns Swipe · XP/Streak · Auto Debrief
